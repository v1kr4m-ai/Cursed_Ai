# Build history

`build-conversation-2026-10-20.zip` is the full Claude Code session that produced this module:
the series writing, the ComfyUI driver, the measured render costs, and the Series Studio tab in
the app above this folder.

Worth digging out of it if you ever need the reasoning behind a decision - why 544x928 and 7
seconds, why references beat a LoRA here, why the frame count snaps to 175. The short versions
of those answers are already in `../README.md` and `../reels/pre-targaryen/SERIES_BIBLE.md`;
the zip is the long version.

Open it with any unzip tool - it holds the conversation transcript, subagent transcripts and
session metadata as plain files.
